# Figure index

No paper-level figure is assigned in this initial software repository.

`sctrajectory plot` generates `reconstruction_audit.png`, `.pdf`, `.svg`, `.json`
and `.md` under `<output-root>/figures/_drafts/<run>` from a validated rollout cache.
The panels compare optimized paths, frozen same-start integration, trajectory
error, total mass, ESS and training-neighborhood distances. The numerical
statistics use all input dimensions; PCA is a display projection only.
